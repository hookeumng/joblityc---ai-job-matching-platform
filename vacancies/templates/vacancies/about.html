О проекте

Job AI — это веб-приложение для поиска и анализа вакансий.

Программа собирает информацию о вакансиях, сохраняет её в базе данных и помогает пользователю выбрать наиболее подходящие предложения.

Как работает система

  • Получает данные о вакансиях.
  • Обрабатывает и сохраняет их в базе данных.
  • Показывает вакансии в удобной витрине.
  • Позволяет установить минимальную зарплату.
  • Анализирует навыки пользователя.
  • Рассчитывает процент соответствия вакансии.

Анализ навыков

Пользователь указывает свои навыки в профиле. Система сравнивает их с требованиями вакансии и рассчитывает процент соответствия.

Благодаря этому наиболее подходящие вакансии автоматически поднимаются выше в списке.

Технологии

Python Django SQLite HTML CSS

Цель проекта

Создать простой интеллектуальный сервис, который помогает соискателю быстрее находить вакансии, соответствующие его навыкам и требованиям к зарплате.
